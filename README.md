# Portfolio

Personal portfolio for Nikhil George. Next.js App Router, TypeScript,
Tailwind CSS v4, statically generated.

```
npm install
npm run dev
```

Content lives in `src/content/` as typed TypeScript. See `AGENTS.md` for the
content model and the factual rules the copy has to respect.

No domain is configured yet. Setting `NEXT_PUBLIC_SITE_URL` enables canonical
URLs, absolute Open Graph image URLs, and a populated sitemap.
